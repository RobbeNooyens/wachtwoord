Hoe wordt je wachtwoord gemaakt?

Je e-mailadres, hoofdwachtwoord en appnaam worden lokaal omgezet in een vast resultaat.

De stappen

  • Spaties worden uit je e-mailadres gehaald en hoofdletters worden kleine letters. Daarna worden je e-mailadres, hoofdwachtwoord en appnaam achter elkaar gezet.
  • De tekst wordt met SHA-384 gehasht in je browser. Dat levert 48 bytes op.
  • Die bytes worden omgezet in tekens. Een wachtwoord begint altijd met een cijfer, kleine letter en hoofdletter; als speciale tekens aanstaan, ook met een speciaal teken.
  • Voor een pincode worden de bytes omgezet in cijfers.

De appnaam is de korte naam die bij je website hoort, zoals MICROSOFT. Het websiteadres en pictogram zijn alleen voor je lijst: ze veranderen het resultaat niet. Alleen een hash en afgeschermde versie van je e-mailadres worden op dit apparaat bewaard.

Pseudocode om over te zetten

Gebruik UTF-8 voor de invoer en SHA-384 voor de hash. De standaardinstellingen geven dezelfde uitkomst als de oorspronkelijke versie: 20 tekens en speciale tekens voor een wachtwoord, of 6 cijfers voor een pincode.

email = lowercase(removeSpaces(email))
input = email + masterPassword + appKey
bytes = SHA384(UTF8(input))

if type == "pin":
    result = ""
    for byte in bytes:
        result += digitCharacters[byte mod 10]
    return first(pinLength) characters of result

characters = digits + lowercase + uppercase
result = digitCharacters[bytes[0] mod 10]
result += lowercase[bytes[1] mod 26]
result += uppercase[bytes[2] mod 26]

if includeSpecial:
    characters += specialCharacters
    result += specialCharacters[bytes[3] mod length(specialCharacters)]

for byte in bytes starting at index 4:
    result += characters[byte mod length(characters)]

return first(passwordLength) characters of result

Goed om te weten

  • Hetzelfde e-mailadres, hoofdwachtwoord en dezelfde appnaam leveren steeds hetzelfde resultaat op. Verander je één ervan, dan krijg je een ander wachtwoord.
  • Bewaar je hoofdwachtwoord goed. Als je het vergeet, kan de app het niet terughalen.
  • De invoer wordt direct achter elkaar gezet, precies zoals in de pseudocode. Gebruik daarom overal dezelfde spelling en hoofdletters.
  • Dit is een eenvoudige deterministische generator, geen complete wachtwoordkluis. SHA-384 wordt hier rechtstreeks gebruikt; er is geen extra sleutelversterking of salt.
  • Bij aangepaste lengtes, typekeuze of tekeninstellingen krijg je uiteraard een ander resultaat dan bij de standaardinstellingen.
