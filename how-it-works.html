Hoe wordt je wachtwoord gemaakt?

Je e-mailadres, wachtwoord en appnaam worden lokaal omgezet in een vast resultaat.

De stappen

  • Spaties worden uit je e-mailadres gehaald en hoofdletters worden kleine letters. Normaal wordt hiervan een SHA-256-hash gemaakt.
  • Vul je bij Oude versie een waarde in, dan wordt die tekst direct gebruikt in plaats van de e-mailhash.
  • De hexadecimale e-mailhash, je wachtwoord en de appnaam worden achter elkaar gezet en met SHA-384 gehasht. Dat levert 48 bytes op.
  • Die bytes worden omgezet in tekens. Een wachtwoord begint altijd met een cijfer, kleine letter en hoofdletter; als speciale tekens aanstaan, ook met een speciaal teken.
  • Voor een pincode worden de bytes omgezet in cijfers.

De appnaam is de korte naam die bij je website hoort, zoals MICROSOFT. Het websiteadres en pictogram zijn alleen voor je lijst: ze veranderen het resultaat niet. Alleen de e-mailhash en een afgeschermde versie van je e-mailadres worden op dit apparaat bewaard; de gewone tekst wordt niet opgeslagen.

Pseudocode om over te zetten

Gebruik UTF-8, SHA-256 voor de e-mailhash en SHA-384 voor de code. De e-mailhash wordt als hexadecimale tekst aan het wachtwoord en de appnaam toegevoegd. Een ingevulde waarde bij Oude versie vervangt die e-mailhash rechtstreeks.

email = lowercase(removeSpaces(email))
emailHash = SHA256(UTF8(email))
    emailSeed = oldVersion if oldVersion is not empty else HEX(emailHash)
    input = emailSeed + password + appKey
bytes = SHA384(UTF8(input))

if type == "pin":
    result = ""
    for byte in bytes:
        result += digitCharacters[byte mod 10]
    return first(pinLength) characters of result

characters = digits + lowercase + uppercase
result = digitCharacters[bytes[0] mod 10]
result += lowercase[bytes[1] mod 26]
result += uppercase[bytes[2] mod 26]

if includeSpecial:
    characters += specialCharacters
    result += specialCharacters[bytes[3] mod length(specialCharacters)]

for byte in bytes starting at index 4:
    result += characters[byte mod length(characters)]

return first(passwordLength) characters of result

Goed om te weten

  • Hetzelfde e-mailadres, wachtwoord en dezelfde appnaam leveren steeds hetzelfde resultaat op. Verander je één ervan, dan krijg je een ander wachtwoord.
  • Bewaar je wachtwoord goed. Als je het vergeet, kan de app het niet terughalen.
  • Om een wachtwoord uit een oudere versie terug te krijgen, vul je bij Oude versie de exacte oude invoer in, meestal het genormaliseerde e-mailadres. Laat het veld leeg voor de huidige methode.
  • De waarden worden direct achter elkaar gezet, precies zoals in de pseudocode. Gebruik daarom overal dezelfde spelling en hoofdletters.
  • Dit is een eenvoudige deterministische generator, geen complete wachtwoordkluis. SHA-384 wordt hier rechtstreeks gebruikt; er is geen extra sleutelversterking of salt.
  • Bij aangepaste lengtes, typekeuze of tekeninstellingen krijg je uiteraard een ander resultaat dan bij de standaardinstellingen.
